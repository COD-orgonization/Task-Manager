# Task-Manager

## Используемые технологии
- LiveSQL
- FastAPI
- pydantic
- uvicorn - локальный сервер (библиотека python)
- HTML/CSS/JS
- Python

## Что реализовано
- Бэто дезайн проета
- База даных
- Бэкэнд на основе FastApi
- Частичное подключение бэкэнда и фротенда (90% от общих подключений)

## Что планируется
- Функции для изменения названия и описания доски
- До подключение всех функций к фронтенду
- Доработка сушествуещего кода
