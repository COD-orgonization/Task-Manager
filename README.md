# Task-Manager

## Используемые технологии
- LiveSQL
- FastAPI
- unicorn - локальный сервер (библиотека python)
- HTML/CSS/JS
- Python

## Что реализовано
- Бэто дезайн проета
- База даных
- Бэкэнд на основе FastApi
- Частичное подключение бэкэнда и фротенда (60% от общих подключений)

## Что планируется
- Добавлеие тоблицы с секциями в доске
- Соединительная таблица секции и доски
- Функции которые создают/изменяют/удаляют секции и соедение с доской
	Примечание:
		Сохраняются уникальные и будут соществовать до тех пор пока на секцию сылается хотябы одна доска
- Подключение остовщийся части бекэнда к фронтенду
